# Сборка и публикация плагина

## Сборка

```sh
cd my_plugin            # внутри plugin.json и main.lua / main.py
zip -r ../my_plugin.mgplugin .
```

Допускается одна вложенная папка в архиве (`my_plugin/plugin.json`).

## Версии и обновления

- Повторная установка файла с тем же `id` заменяет плагин; если он был включён — перезапускается.
- Меняйте `version` при каждом выпуске.
- `min_sdk` — минимальная версия SDK; если клиент старее, плагин не запустится и покажет ошибку.

## Аватарка и анимация

- `icon` — квадратная PNG/JPG от 96×96, показывается в круге.
- `animation` — Lottie JSON (как стикеры Telegram), проигрывается по кругу вместо аватарки.

## Безопасность

Плагин работает с правами приложения: читает все чаты, может отправлять сообщения от вашего имени
и вызывать любой код Telegram. Устанавливайте плагины только из источников, которым доверяете,
и читайте исходный код перед установкой — `.mgplugin` это обычный zip.
